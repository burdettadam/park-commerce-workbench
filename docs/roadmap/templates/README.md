# Artifact templates

These templates are intentionally unfilled. They are inputs for actual work, not executed evidence or generated git-agent guidance.

| Template | Use |
| --- | --- |
| `active-goal.md` | Canonical accepted goal/integration record; create only after authority exists |
| `work-record.md` | Per-branch writer progress and owned resources |
| Each goal's `manifest.template.json` | Expected criterion/artifact/check/review structure for a fixed candidate |
| `review.md` | Independent first findings and current-candidate disposition |
| `validation.md` | Intended-use validation by the assigned owner |
| `decision.md` | Actual acceptance/escalation decision, separate from release authority |
| `handoff.md` | Whole-goal checkpoint inventory and actual retrieval |
| `milestone-acceptance.md` | Combined candidate gate across included goals |
| `release-record.md` | Actual human approval, merge/artifact/tag/health observations |
| `process-observations.md` | Live workflow measurements and controlled experiments |

Copy only needed templates to an accepted active goal. Never prefill human names as approvals, invent source hashes or convert a template status to passed without the required observation.
