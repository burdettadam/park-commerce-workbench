# Proposed implementation roadmap

The detailed roadmap is now **[docs/roadmap/README.md](roadmap/README.md)**: 10 milestones, 30 bounded goal proposals, 120 acceptance criteria and 90 goal-specific artifact requirements.

Each goal has scope, dependencies, independent expected results, proposed source/configuration deliverables, evidence paths, review rules and an unfilled manifest template. No goal is claimed accepted or completed merely because candidate source exists.

Start with **[G-0001: adopt the existing initializer guidance](roadmap/goals/G-0001/README.md)**, then **[G-0002: exact-version regression challenge](roadmap/goals/G-0002/README.md)** and **[G-0003: worktree/handoff drill](roadmap/goals/G-0003/README.md)**. The [current-state audit](roadmap/CURRENT-STATE-2026-10-12.md) identifies what already ran and what remains unaccepted. The first application-validation milestone is **[M1](roadmap/milestones/M1.md)**; it rechecks the existing candidate from clean inputs and completes missing UI/browser evidence before feature expansion.

The earlier broad G0–G6 themes are preserved in the [crosswalk](roadmap/TRACEABILITY.md). After adoption, each active goal's accepted record is authoritative; the roadmap remains a planning/navigation input, not a second execution-state database.
