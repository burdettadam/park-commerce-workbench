## Candidate baseline rationale

Use Java 21 with Spring Boot **4.1.1**, not an older unverified starter template. Boot 4 modularizes starters: this source uses `spring-boot-starter-webmvc`, `spring-boot-starter-restclient`, `spring-boot-starter-flyway`, and `spring-boot-starter-opentelemetry`. It imports Jackson 3 `tools.jackson.databind.ObjectMapper` and configures Mongo via `spring.mongodb.uri`.

Vaadin **25.3.0** follows the selected Java 21 / Boot 4.1 family. Its workstation baseline calls for Node 24 and npm 11.3+. Angular framework **21.2.25**, CLI/build **21.2.26**, and TypeScript **5.9.3** use a documented supported compatibility family. The Angular patches were selected after a local npm audit and passed build, type, and state checks on Windows; the refreshed lockfile audited with zero reported vulnerabilities on 2026-10-12. Testcontainers **2.0.5** uses `testcontainers-mongodb`, `testcontainers-mysql`, and `testcontainers-junit-jupiter` with their current module package names.

Database image tags **mysql:8.4.11** and **mongo:8.0.26** are pinned test/development fixtures, not a claim of latest patch status or Aurora engine availability. Aurora version selection is not made by this local ZIP. Docker base images use readable tags; immutable digest pins and vulnerability checks remain release gates.

Maven 3.9.11 is selected in the container build; a host Maven 3.9+ is accepted by the source. No fake wrapper executable or unverified embedded Maven binary is included. The Angular lockfile was generated by npm; Vaadin frontend resolution remains optional local work.
