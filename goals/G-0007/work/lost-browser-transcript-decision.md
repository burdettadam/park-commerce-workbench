## Proposed prevention

Use unique timestamped or attempt-numbered raw filenames for every browser command, including failed runs. Preserve each file before rerun; publish only sanitized copies after scanning for credentials and user paths. This is a process correction for later work, not a retroactive cure for the missing output.
