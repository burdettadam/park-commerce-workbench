# G-0009-A03 — public quote contract examples and compatibility checks

Fixed source S: `6578753c94674d95793f3ffd82ad7e67d9e98c4e`.

The product's [pricing contract](../../../../docs/project/pricing-contract.md) now includes synthetic REST creation, REST `NOT_FOUND` problem, and GraphQL error examples. It defines inclusive rates, the park-local calendar, one 900-second quote lifetime, half-up discount on each variant subtotal, single-offer policy, immutable snapshot fields, role boundaries and explicit exclusions. `docs/project/api-contracts.md` remains the API overview. The examples use fictional cents and an illustrative ID; they are not issued credentials or orders.

`contracts/pricing/quote-api-v1.json` pins GraphQL field names/types and the stored Java quote record shape. `scripts/pricing-contract.test.mjs` tests the SDL source and deliberately altered fixture expectation; 29/29 checks passed at S. These source-only checks are narrower than runtime compatibility. The real MySQL/Spring `QuoteContractIT.serializedQuoteAndDomainErrorsKeepConsumerShape` asserts the exact REST quote field set, nested line fields, REST numeric money/version representations, selected GraphQL field set and string money/version representations, an invalid owner selection with no quote issuance, and REST/GraphQL `NOT_FOUND` error code/shape. `ordinaryQuoteReadsUseTheSameOwnerAndRoleBoundaryAcrossTransports` pins owner/other/employee/internal/anonymous/unknown behavior. A field removal/rename, changed number/string representation or changed domain error code fails an executed assertion.

REST `Money` is `{ "cents": <integer> }`; GraphQL `Money` has string `cents`, two-decimal `amount`, and `currency: "USD"`. GraphQL resolver failures may arrive with HTTP 200 and `errors`; clients must inspect the envelope. GraphQL parse/coercion errors occur before the domain resolver and are not promised a custom domain code. The quote does not promise event inventory or payment. Unsupported scope: tax compliance, real age/residency checks, multiple currencies, offer stacking and dynamic revenue management.

The candidate tightens malformed date, abbreviated UUID and omitted-quantity inputs as documented; stored quote fields and complete existing requests remain compatible. External independent consumers and deployment coexistence have not been validated by this local synthetic exercise.
